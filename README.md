# ihatepdf-standalone

Standalone Windows desktop builds (Electron wrappers) for dicebanned.art tools:

- iHatePDF
- iHateCrop
- iHateCards
- iHatePhoto
- visaHater

Download the latest release, unzip, and run the .exe inside. These are thin desktop shells that load the live web app at dicebanned.art, so they always reflect the latest version.
